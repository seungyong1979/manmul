- **아이콘**: Font Awesome 6 (CDN)

## 5-1. 반응형 디자인 (모바일 대응)
스마트폰에서도 전체 콘텐츠를 편하게 볼 수 있도록 4단계 브레이크포인트로 세밀하게 대응했습니다.

| 브레이크포인트 | 대상 | 주요 대응 |
|---|---|---|
| ≤1024px | 태블릿 가로 | 상단 메뉴 → 햄버거 메뉴 전환, 2단 그리드 축소 |
| ≤768px | 태블릿 세로 / 큰 스마트폰 | 폰트·여백 축소, **일정표: 표(Table) → 카드 리스트로 전환**(가로 스크롤 없이 한눈에 확인) |
| ≤480px | 일반 스마트폰 | 대부분의 카드 그리드 1~2열, 버튼/배지 세로 스택, 터치 영역 확대 |
| ≤360px | 소형 스마트폰(구형 기기) | 그리드 1열, 컨테이너 여백 축소 |

추가로 다음 사항을 적용했습니다.
- 모든 버튼/링크/메뉴 항목에 **최소 44px 터치 영역** 확보 (`pointer: coarse` 미디어쿼리)
- 모바일 메뉴는 뷰포트 높이를 넘지 않도록 스크롤 처리
- 지도(iframe) 높이를 화면 크기에 맞춰 축소
- Playwright로 데스크톱(1280px)·모바일(390px, iPhone 기준) 렌더링을 모두 검증 완료

## 6. 아직 구현되지 않은 기능

- 실시간 부스/퀘스트 진행 현황판
- 다국어(영/중/일) 버전
- SNS 공유 최적화 OG 메타 이미지(현재 기본 메타 태그만 적용)

## 7. 다음 개발 제안
1. 참가 신청/사전 설문이 필요하다면 RESTful Table API로 `registrations` 테이블을 만들어 폼 연동
2. OG 이미지·title/description 메타 태그를 포스터 이미지 기준으로 보강해 카카오톡/SNS 공유 미리보기 개선
3. 실제 행사 후 사진/후기를 담을 갤러리 섹션 추가 검토
4. Publish 탭에서 배포 후 QR코드를 생성해 오프라인 홍보물에 부착

추후 신청/설문 기능이 필요하면 안내해 주시면 Table API 스키마를 설계해 드립니다.
