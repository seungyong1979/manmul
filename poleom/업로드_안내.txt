2026 순천 생태문명도시 포럼 모바일 자료집 — 사용 안내

1. 미리 보기
이 폴더의 index.html을 브라우저로 열면 됩니다.
index.html만 따로 옮기지 말고, 나머지 파일과 assets 폴더를 함께 보관해 주세요.

2. 웹에 올리기
이 폴더 안의 모든 파일과 assets 폴더를 같은 구조로 웹 호스팅 공간에 업로드하세요.
사이트 기본 주소 또는 업로드한 폴더 주소로 접속하면 index.html이 열립니다.
별도의 설치·빌드·로그인·데이터베이스가 필요하지 않습니다.
블로그나 게시판에 HTML 파일을 첨부하는 방식이 아니라, HTML/JS를 제공할 수 있는 웹 호스팅이 필요합니다.

3. 포함 기능
- 휴대전화와 노트북에 맞춰 배치되는 화면
- 화면 하단에 항상 표시되는 PDF 다운로드
- 발표자·제목 검색, 1부·2부 분류
- 인사말·발제·토론 13개 자료 큰 글씨 읽기
- 글자 크기 조절(17~27px)
- 원본 페이지 이미지 보기 및 확대
- 원본 83쪽 PDF 포함(assets/forum.pdf)

4. 파일 구성
index.html: 행사 소개·일정·화면 구성
style.css: 디자인 및 휴대전화 대응
app.js: 검색·읽기·글자 크기 조절
data.js: 자료집 본문
assets/: 원본 PDF와 원본 페이지 이미지

5. 본문 안내
모바일 본문은 자료집에서 추출·전사한 텍스트입니다. 원문의 주장·수치에 대한 별도 사실검증을 뜻하지 않습니다.
슬라이드의 도형 관계와 표의 행·열, 각주 등은 원본 페이지 보기와 PDF를 함께 참고하세요.
윤희철 발제는 이미지형 슬라이드의 주요 문구를 읽기 순서에 맞게 전사했습니다.
PDF 페이지 숫자는 파일의 첫 표지를 1쪽으로 센 번호입니다.
자료집의 조찬 시간은 다른 일정과 충돌하는 표기가 있어 주요 일정 목록에서 생략했습니다.
식전 공연은 사용자 제공 내용에 따라 '개회 전·약 10분, 유토'로 반영했습니다.

6. PDF 수정 시
assets/forum.pdf 교체만으로 다운로드 파일은 변경됩니다.
모바일 본문과 페이지 이미지도 함께 바꾸려면 data.js 및 assets/page-*.jpg를 갱신해야 합니다.

외부 게시 없이 파일 형태로 제작했습니다. 폴더 구조를 유지하면 하위 경로에서도 사용할 수 있습니다.
